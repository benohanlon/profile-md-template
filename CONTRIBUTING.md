# Contribute to the starter

We welcome clearer setup instructions, fixes for Markdown retrieval or the copy controls, and examples of adventure paths that worked for you.

- For a bug or idea, open an issue. Include what you tried, what happened and which browser or AI you used if it matters.
- For a fix, fork this starter and open a pull request. Explain the problem and what you verified. The maintainer reviews changes before merging them.
- To share your own profile or adventure, post a public link in [Discussions](https://github.com/benohanlon/profile-md-template/discussions).

Run `node scripts/build.cjs` after editing the source. Run `node scripts/build.cjs --check` before opening a pull request. Keep examples anonymous or share them with permission.
