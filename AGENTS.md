# Rebuild this profile

These instructions are for the AI editing the repository.

1. Read [profile.md](profile.md). Its standalone italic paragraphs explain how to make each section your own. [benohanlon.md](https://benohanlon.md/) is a finished example of the profile and adventure.
2. Replace Rowan Ellis, the fictional cases and the starting choices with material the owner supplies. Remove the fictional-example notice once the profile uses real material. Ask about gaps that matter and omit unverified claims. Confirm which contact details the owner wants public.
3. Keep the public **Agent instructions** and **Run the full OODA loop** headings. These guide visitors’ AIs through the adventure.
4. Edit the Markdown source, then run `node scripts/build.cjs` and `node scripts/build.cjs --check`. Preview `index.html` and `adventure.html`. Confirm the links and copy actions point to the new profile.
5. Show the owner the preview and ask before publishing their material.
