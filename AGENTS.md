# Rebuild this profile

These instructions are for the AI editing the repository.

1. Start with the pilot’s CV or résumé. If they haven’t supplied it, ask for it before drafting.
2. Read [profile.md](profile.md) and follow its standalone italic instructions. Use [benohanlon.md](https://benohanlon.md/benohanlon.md) only as a worked example of structure and how the adventure uses evidence. Base all claims about the pilot on their résumé and the links, notes or answers they supply. Ask focused questions about material gaps or unclear claims. Omit details that remain unsupported and drop optional sections without evidence. Tailor the starting choices to questions visitors can answer from the resulting profile.
3. Fill the placeholders using the pilot’s sources. Ben’s public profile is the live worked example. Replace the opening with the pilot’s positioning, origin and supported proof. Cover work preferences, sectors and cross-sector capabilities under **Where I’m a good fit**. Add supported cases, the pilot’s method, writing or projects, and approved public contact routes. Under **Agent instructions**, retain **Opening**, **Where would you like to begin?**, **Waypoints** and **Run the full OODA loop**. Rewrite their content around the pilot. Make each opening choice point to an existing heading or public source. Keep OODA last.
4. Remove unfilled placeholders and standalone italic rebuild notes from the personalised copy. Build from profile.md with `node scripts/build.cjs`. This generates the homepage, adventure and agent-quickstart.md. Run `node scripts/build.cjs --check`. Open both pages, follow each choice, and confirm the copied prompts use the new site’s URLs. Read the output for any facts, example names or links that do not belong to the pilot.
5. Show the owner the preview and ask before publishing their material.
